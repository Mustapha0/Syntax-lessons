# Minimalist Syntax — Interactive Study Companion

A static, GitHub Pages-ready learning site covering all ten chapters and every numbered subsection listed in the contents of Andrew Radford, *Minimalist Syntax: Exploring the Structure of English*.

## Features
- 10 chapter selectors and 95 subsection lessons
- Four guided stages per subsection: core question, example, analysis routine, checkpoint
- Animated lesson-player style, captions, progress indicator, step navigation and playback speed
- Optional browser speech synthesis and keyboard shortcuts
- Original knowledge-check question for every subsection
- Responsive light/dark colour scheme and reduced-motion support
- No frameworks, build step, external dependencies or network calls

## Run locally
Open `index.html` in a modern browser. For a local server, run `python -m http.server 8000` in this directory and visit `http://localhost:8000`.

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload the contents of this folder (keep `index.html` at the repository root).
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment and open the published URL.
